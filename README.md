# Sketchbook demo

[Open the current sketchbook](https://niyamax.github.io/sketchbook/) · [Public source and previews](https://github.com/niyamax/sketchbook)

A quiet, interactive sketchbook with desktop page spreads and mobile paper folds.
All sketches were generated with AI for this demo.

This repository preserves the earlier compiled demo and its publishing workflow for existing links. The public application source, desktop and mobile previews, setup instructions and automatic deployment now live in [niyamax/sketchbook](https://github.com/niyamax/sketchbook).
